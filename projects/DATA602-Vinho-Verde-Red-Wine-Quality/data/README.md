# Data

**Source:** [Red Wine Quality — Kaggle (Cortez et al., 2009)](https://www.kaggle.com/datasets/uciml/red-wine-quality-cortez-et-al-2009)

- `winequality-red.csv` — 1,599 *Vinho Verde* red wine samples from production
  plants in northwestern Portugal (May 2004 – February 2007), with 11
  physicochemical measurements plus a 0–10 expert quality score. This is the
  only file used in the analysis.
- `winequality-white.csv` — companion white-wine dataset from the same UCI
  source, included for completeness but **not used** in this project (scope
  was red wine only).
