# DATA 612 Assignments

**Course:** DATA 612 – Decision Analytics, University of Calgary
**Type:** Group assignments

Two case-based group assignments applying simulation and optimization to business decisions,
alongside the standalone [Vaccine Inventory Optimization](../DATA612-Vaccine-Inventory-Simulation/)
project.

| Assignment | Summary |
|---|---|
| [Assignment 1 — Landhills Winery](Assignment-1-Landhills-Winery-Blending-Optimization/) | Linear program (Gurobi) maximizing wine-blending profit under regulatory/quality constraints ($809,911 optimal profit), extended to a mixed-integer program handling a supplier's volume discount (+6.5% profit) |
| [Assignment 2 — Konys, Inc.](Assignment-2-Konys-Procurement-Strategy/) | Monte Carlo simulation (with Bilal Naseem, Sergio Almeida) comparing purchase vs. option contracts for LCD module procurement under demand/price uncertainty; recommended strategy improves expected profit 30.9% over the best purchase-only option |

See each assignment's own README for full problem framing, approach, and results.
