# DATA 614 Assignments

**Course:** DATA 614 – Advanced Data Analytics, University of Calgary
**Author:** Bhuvan Dubey

Two individual assignments building up the course's statistical-learning and deep-learning/NLP
toolkits, alongside the standalone [Insurance Fraud Detection](../DATA614-Insurance-Fraud-Detection/)
group project and the [LLMs in Business Analytics](../DATA614-LLM-Business-Analytics/) white paper.

| Assignment | Summary |
|---|---|
| [Assignment 1 — Statistical Learning](Assignment-1-Statistical-Learning/) | EDA/diagnostics, logistic regression with cost-sensitive thresholding, LDA/QDA/KNN comparison, PCA, K-means/hierarchical clustering, random forest, and a Power BI dashboard |
| [Assignment 2 — Deep Learning, Time Series & NLP](Assignment-2-Deep-Learning-Timeseries-NLP/) | Neural networks (purchase-intent & housing-price prediction), ARIMA/Holt-Winters forecasting, SVM accent classification (81.6% accuracy), and NLP/text mining with sentiment analysis |

See each assignment's own README for full problem framing, approach, and results.
