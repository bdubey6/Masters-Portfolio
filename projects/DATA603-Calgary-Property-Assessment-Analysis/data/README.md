The raw parcel-level dataset (`Current_Year_Property_Assessments_(Parcel).csv`)
was not included in this repo — the City of Calgary's Current Year Property
Assessments file covers every taxable parcel in the city and is too large for
version control here.

Source: City of Calgary Open Data Portal — Current Year Property Assessments (Parcel)
https://data.calgary.ca/Government/Current-Year-Property-Assessments-Parcel-/4bsw-nn7w

To reproduce the analysis, download the current-year CSV from the link above,
place it in this folder as `Current_Year_Property_Assessments_(Parcel).csv`,
and run `code/Community_Assessed_Value_Analysis.Rmd`.
